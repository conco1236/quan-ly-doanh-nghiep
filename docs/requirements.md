# Nhật ký yêu cầu

Tài liệu này là nguồn theo dõi các yêu cầu đã được chủ sở hữu ghi nhận trên GitHub. Mỗi issue mang nhãn `requirement` sẽ tạo một pull request chỉ cập nhật nhật ký này; pull request chỉ được tự động merge sau khi toàn bộ CI bắt buộc đạt.
